# 21 岁生日快乐 🎂

送给猪油渣的一张全屏生日贺卡：音乐盒生日歌、九张拼贴照片、生日蛋糕和一封小信。适配手机、iPad 和电脑。

[打开生日网站](https://zyu79291-web.github.io/birthday-21/)

## 打开惊喜

轻点画面空白处，或点击画面上的继续按钮，就能继续看下一段惊喜。无需上下滑动，画面中不显示页码、圆点或上一页／下一页导航。最后停留在完整的生日祝福上，点空白处不会重新开始。

照片穿插在生日贺卡中，点击照片可放大查看。蛋糕出现时，点击「吹蜡烛」即可直接熄灭蜡烛、洒下彩纸，再点一次可以重新点亮，无需输入内容。点击信封可拆开生日信，继续轻点即可读完。

## 音乐

打开网页会尝试自动循环播放生日歌。如果浏览器阻止带声音的自动播放，点「开启生日惊喜」或画面其他位置即可开始；右上角音乐按钮可以暂停。切换画面不会重播歌曲，也会保留你的暂停状态。

## 发布与文件

GitHub Pages 使用 `main` 分支的根目录；推送更新后自动发布。网站使用相对资源路径，无需安装依赖或构建，`.nojekyll` 保留在根目录。

- `index.html`：生日贺卡内容
- `style.css`：适配手机、iPad 和电脑的全屏拼贴排版
- `app.js`：画面切换、音乐、照片和蛋糕互动
- `assets/`：九张照片、生日歌和图标

英文字体使用 Google Fonts，无法联网时自动使用系统备用字体。
