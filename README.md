# 21 岁生日快乐 🎂

送给猪油渣的生日网站，包含九张照片、生日歌、彩纸、许愿吹蜡烛和生日信。电脑和手机均可浏览。

## 在 GitHub Pages 发布

将本目录全部文件上传到仓库根目录，在 **Settings → Pages** 中选择 **Deploy from a branch**，选择 `main` 分支和 `/ (root)` 目录后保存。网站使用相对资源路径，可用于仓库项目的 Pages 地址。

## 音乐与互动

网页打开后会尝试循环播放音乐盒版生日歌。部分手机和浏览器会阻止带声音的自动播放；轻点「开启生日惊喜」或页面其他位置即可开始播放，也可以用右上角按钮暂停。

点击照片可放大浏览并切换照片，点击「许个愿，吹蜡烛」可写下愿望，点击信封可拆开生日信。愿望只保留在当前页面中，不会提交到服务器。

## 文件

- `index.html`：网页内容
- `style.css`：页面样式
- `app.js`：音乐和交互
- `assets/`：九张照片、生日歌与网站图标
- `.nojekyll`：让 GitHub Pages 直接发布静态文件

网站本身无需安装依赖或构建。英文字体使用 Google Fonts，无法联网时会自动使用系统备用字体。
